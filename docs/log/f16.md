# F16 — Hosted recipes print the live DashScope model id

## What changed

`factory/tools/seat.mjs` now reads `writerModel` from `factory/project.json` at startup and passes it into the `qwen-code` and `pc-dashscope` recipe templates (converted from static strings to functions). Hosted DashScope launch lines interpolate the live id instead of a hardcoded model name.

- Added `import { readFileSync } from "node:fs"`
- Added `const writerModel = JSON.parse(readFileSync(...)).writerModel`
- `qwen-code` and `pc-dashscope` recipes: string → `(m) =>` function, hosted `--model` lines use `${m}`
- Recipe output handler: `typeof entry === "function" ? entry(writerModel) : entry`
- Local Ollama lines keep literal `qwen3-coder`
- Windows hosted lines use `$env:OPENAI_API_KEY=$env:DASHSCOPE_API_KEY`

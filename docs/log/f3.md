# F3: DashScope URL correction and Windows support

## Issue
- Incorrect DashScope launch URL in pc-dashscope recipe
- Missing Windows environment variable support

## Resolution
- Fixed DashScope URL from `https://dashscope.aliyuncs.com/compatible-mode/v1` to `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`
- Added Windows stanza with `$env:OPENAI_BASE_URL` and `$env:DASHSCOPE_API_KEY`

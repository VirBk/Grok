# Control-plane derivation

Required reading for the control plane — Grok in the cloud or Claude Code on the desktop. Not required for a writer seat. A successor that will issue, stamp, or drop reads this with AGENTS, BOARD, and traps.

The method is exhaustive on containers and issuances. It is not a long essay.

## 1. A ZERO names every container

Before “nowhere”, “no scope”, “drop them”, or “not in the repository”:

```
node factory/tools/scopeSearch.mjs TOKEN
```

The command prints **every** container, including the empty ones. An empty container you named is evidence. One you did not open is not.

Closed list:

| Container | What it is |
| --- | --- |
| `board-now` | The live queue / `now` |
| `board-rest` | The rest of the board: wave tables, design rows, ledger |
| `docs` | Markdown, HTML, YAML other than the board |
| `source` | Product and factory code, JSON other than the board |
| `tests` | Specs and self-tests |
| `other` | Everything else git tracks |

A markdown-only grep of the queue line is the miss this file exists to stop. The scope lived in the **same board**, further down, and in **source**. The stamp said ZERO. The objects did not.

A suffix that is wave vocabulary (`S` for screens, `T-` for a journey) is reconstructed from the table that defined the wave. It is not invented, and it is not dropped because the last stamp called it a ghost.

The last stamp is a lead. Re-derive against the objects.

## 2. A named issuance is a fetch, not an ask

If the record names a law, circular, IRR, RFC, or PDF: retrieve it. Quote the section. Record the URL.

Ask the owner only when the document cannot be found, or sits behind a closed gate. “Blocked on the citation” with no fetch is a diary.

If the fetch 404s, is paywalled, or proves no such circular exists, stamp **that miss**. Do not wait for a document the fetch already disproved.

An agency still collecting is a **second fact**. It does not erase the statute. Stamp both. Transcribe the issuance. Do not collapse collection-in-practice into “no legal basis.”

## 3. Exhaustive, not long

Open the named document. Open the containers. Quote. Stop. Do not start a study. Do not fill a seat because a slot is empty. Do not drop a name you have not searched in source.

## 4. Check

`node factory/tools/scopeSearch.mjs --self-test` is a landing-gate step. It fails if a token that lives only in source is reported absent, and if a report omits an empty container.

A `blocked-on-issuance` stamp without a fetch URL is refused by this file. The control plane writes the URL or the miss in the ledger row.
